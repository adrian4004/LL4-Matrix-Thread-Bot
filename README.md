# LL4 Matrix Thread Bot

A small, rule-based Matrix bot: whenever someone writes a new message in the main timeline of a room the bot is in, it opens a thread on that message. No LLM, no AI — just rules.

Work in progress — see [`.agent/plans/thread-bot-mvp.md`](.agent/plans/thread-bot-mvp.md) for the behaviour spec.
